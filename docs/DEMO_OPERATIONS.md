# 灵枢现场演示操作手册

## 1. 演示前检查

1. 执行 `.\scripts\verify-demo.ps1 -SmokeRun`，确认总状态为 `ok`。
2. 执行 `.\scripts\start-demo.ps1`，使用浏览器打开控制台地址。
3. 顶部应显示“仿真环境”，模型状态在离线演示时显示确定性降级。
4. 左侧 MASP 状态应显示版本已锁定，不应出现脏工作区提示。
5. 演示电脑关闭系统更新、代理弹窗和无关通知，保持电源连接。

## 2. 主演示路线

### 调度总览

选择适合现场时长的预置场景，运行当前场景基线。回放车辆轨迹，说明路径、时序和资源占用来自 MASP，页面指标可以回溯到本次运行文件。

### 自然语言插单

点击“注入紧急任务”。系统生成结构化任务意图；若当前为离线模式，界面会标明本地降级。运行数字孪生后进入方案仿真，将插单方案与基线按同一口径比较。

讲解重点：大模型或降级解析器只形成业务意图，路线、SIPP 时窗和预约冲突仍由确定性引擎计算。

### 群车智能体

在方案仿真中选择智能体策略并运行。展开策略证据，展示模型版本、候选来源、推理次数、规则接管原因和 Top-K guardian 结果。没有配置 checkpoint 时，系统应明确回退到规则基线，而不是伪装成模型输出。

### 通道封闭与审批

点击“推演通道封闭”。完成 What-if 后提交审批，在风险审批页查看 R3 申请、关联运行和影响资源。批准后只能提交到仿真环境，不能下发真实车辆。

### 异常处置

进入“异常诊断”，点击“一键演示”中的“等待环”。系统应显示循环车辆和 MASP 恢复可行性。点击“AI 分析原因”，说明每条推断只能引用页面已有的 `EV-*`。完成“受控倒退推演”后提交审批，风险页应出现 `REQUEST_RECOVERY` 申请。

时间允许时再演示“工位停用”，选择“暂停关联任务推演”。地图应高亮实际工位，页面应列出关联任务和车辆。

### 评测与数据资产

进入评测中心，使用少量种子运行规则、Top-K 和智能体策略对比。展示均值、标准差、置信区间、安全门槛和失败案例。生成数据资产包后，说明数据已经脱敏和固定划分，但转为生产训练数据前仍需完成来源授权和人工复核。

## 3. 三分钟压缩路线

1. 运行基线并回放，说明 MASP 的确定性安全职责。
2. 注入紧急任务并展示结构化意图与方案比较。
3. 一键注入等待环，展示 `EV-*` 诊断、受控倒退推演和 R3 送审。
4. 打开运营审计，收束到“意图、仿真、审批、证据可追溯”。

## 4. 异常情况处理

DeepSeek 超时或返回错误：保持当前页面，指出系统已自动使用确定性降级，然后继续演示。不要现场修改密钥。

仿真未完成：切换到较小预置场景重新运行，保留失败记录用于说明可追溯性，不要手工改写结果文件。

浏览器页面无响应：先刷新页面；后端控制台仍运行时，已有数据不会丢失。若后端退出，重新执行 `start-demo.ps1`。

文件校验失败：停止演示服务，重新解压原始 ZIP。不要使用校验失败的包继续演示。

端口冲突：停止占用程序，或用 `start-demo.ps1 -Port 8890` 启动并访问对应地址。

## 5. 表述边界

- 说“仿真结果”或“评测结果”，不说“已在生产节省”；
- 说“大模型理解意图、组织证据解释”，不说“大模型规划安全路线”；
- 说“处置候选已送审”，不说“AI 已执行恢复”；
- 说“支持智能体策略并受规则接管保护”，未加载权重时不说“当前由 PPO 控车”；
- 说“当前只连接数字孪生”，不暗示已经接入 WMS、RCS 或真实车辆。
