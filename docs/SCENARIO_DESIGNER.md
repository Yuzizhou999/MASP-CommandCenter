# 场景设计工作台

第三阶段在灵枢前端增加“场景设计”视图，用于把比赛要求中的地图和任务配置落实为可操作流程。工作台从已有MASP运行场景创建独立草稿，草稿保存为场景包，不会修改MASP固定场景文件。

## 使用流程

1. 在左侧选择运行场景，指定草稿ID，点击“从运行场景创建”；
2. 在地图画布中拖动节点调整坐标，添加CP安全节点，选择起点、终点和车型后添加有向边；
3. 在右侧节点属性和任务流面板中修改节点类型、任务取放点、释放时间和优先级；
4. 在任务生成参数区编辑JSON，支持固定间隔、泊松和分时波峰，到达结果写回当前任务流；
5. 点击“保存”写入草稿，点击“校验”查看Schema和领域校验结果；
6. 校验通过后编译仿真资产，确认结果后发布不可变仿真版本。

编辑接口使用revision保护。多人或多个页面同时编辑时，如果revision已经变化，后端返回409，当前页面需要重新加载草稿后再保存。发布版本仍然只用于数字孪生仿真，前端没有真实车辆控制入口。
