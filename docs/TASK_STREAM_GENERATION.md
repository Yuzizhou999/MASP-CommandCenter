# 参数化任务流生成

第二阶段增加了面向场景包的任务流生成器。生成参数与场景包分离，地图可以保持不变，任务到达模型可以独立替换，生成结果仍然遵循 `TaskStreamSpec` 和现有调度运行时字段。

## 运行

在场景设计工作台的任务流区域填写生成参数，或调用`POST /api/v1/scenario-drafts/{packageId}/generate-tasks?expectedRevision=N`。生成结果直接写回当前草稿，并增加revision。

支持三种到达方式：

- `fixed_interval`：从起始时刻按固定间隔生成；
- `poisson`：按指数分布间隔生成；
- `time_windows`：按多个时间窗分别配置固定间隔或泊松到达，用于模拟分时波峰。

OD候选必须同时满足：存在对应工作站、工作站具备取/放能力、车型兼容、场景中存在对应车队，并且在该车型有向图中可达。不可用候选会被过滤；全部不可用时直接返回领域错误，避免把无效任务带入编译链路。

生成器使用独立的 `random.Random(seed)`，不会污染进程全局随机状态。同一场景、同一生成参数和同一 `seed` 会得到相同的任务ID、载荷ID、到达时间、优先级和截止时间，便于复现实验。
