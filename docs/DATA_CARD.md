# 数据卡

## 数据范围

本项目使用四类数据：

| 数据类型 | 来源 | 用途 | 当前存储 |
|---|---|---|---|
| 路网与工位 | MASP `generated/` | 拓扑校验、地图、路径规划 | MASP 仓库只读 |
| 车辆与任务场景 | MASP `scenarios/` | 数字孪生输入 | MASP 仓库只读 |
| SOP 与安全规则 | 本仓库 `knowledge/` | 检索引用和边界说明 | Markdown |
| 运行与审计数据 | 灵枢运行时生成 | 回放、比较、验证 | JSON、JSONL |
| 故障诊断证据 | MASP 计划、事件、指标与内部 SOP | 原因解释、What-if 与审计 | `EV-*` JSON |

## 数据处理

当前演示数据不包含人员姓名、手机号、客户订单或生产密钥。运行过程会生成结构化意图、仿真输入、计划、事件、指标和审批记录。

数据质量控制包括：

- 节点、边、工位和资源 ID 必须存在于固定 MASP 资产；
- 任务起终点必须与车型拓扑兼容；
- 时间字段使用毫秒整数并检查先后关系；
- 每次运行记录场景、种子、策略、引擎提交和结果摘要；
- 界面指标直接读取结果文件，不重复手工计算；
- 审计记录使用 UTC ISO 时间和唯一事件 ID。
- 故障注入只选择已完成 traverse 段的结束节点；
- 诊断证据 ID 在单个事故内唯一，实体 ID 必须存在于源运行；
- AI 引用由后端白名单复核，未知证据会触发整份报告降级；
- 载货任务在隔离分支中移出自动任务队列并标记人工转运。

## 数据集用途限制

当前运行数据用于比赛演示、回归验证和后续评测集设计，不应直接视为可用于模型训练的高质量数据集。若以高质量数据集方向另行申报，需要补充：

- 数据来源授权和个人信息影响评估；
- 去标识化、脱敏和访问权限；
- 标注规范、双人复核和一致性指标；
- 训练、验证、测试集隔离与去重；
- 数据版本、变更记录和退出机制；
- 偏差、覆盖率和质量报告。

## 保留与删除

比赛版本默认将 `runs/` 和 `data/` 中的运行文件排除在 Git 之外。生产试点应配置数据分级、最小保留期、自动清理、加密存储、访问审计和备份恢复策略。
