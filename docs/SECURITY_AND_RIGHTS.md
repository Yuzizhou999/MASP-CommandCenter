# 安全与权益说明

## 执行安全

当前系统只开放仿真工具。后端健康接口固定返回 `fieldExecutionEnabled=false`，意图存储拒绝任何非 `simulation` 环境提交。

大模型不能执行以下操作：

- 生成或写入车辆路线；
- 写入资源预约表；
- 解除停车或安全联锁；
- 绕过主管审批；
- 控制真实车辆或现场控制器；
- 修改固定的 MASP 引擎版本。
- 在真实设备或 MASP 引擎中制造故障；
- 对载货任务进行无人工确认的自动重派。

## 应用安全

- DeepSeek 密钥只在后端读取，不进入前端包；
- Pydantic 使用 `extra=forbid` 拒绝未定义字段；
- 外部模型返回必须通过 JSON 和 Schema 校验；
- 群车策略 checkpoint 只能由服务端登记，客户端不能指定文件路径；
- 学习策略仅能提交候选顺序，所有候选仍须通过 SIPP、预约和 guardian 校验；
- 模型权重缺失、契约不兼容、推理异常或候选不可行时强制规则接管；
- 资源与节点由 MASP 拓扑进行白名单校验；
- R3 审批检查状态、意图 ID 和世界版本；
- 审计记录覆盖模型解析、仿真、审批和提交；
- 故障诊断对证据 ID、车辆、任务和允许动作做完整输出校验；
- 故障 What-if 明确标记 `simulationOnly`、`manualTransferRequired` 和分支建模限制；
- FastAPI 只允许已知开发源跨域访问。

生产试点仍需补充企业身份认证、角色权限、CSRF 防护、速率限制、密钥托管、日志脱敏、传输加密、依赖扫描和渗透测试。

## 技术权益

赛前需要由项目负责人确认并留档：

1. MASP 源代码、地图模型和场景数据的使用权；
2. DeepSeek API 账号、服务协议和数据处理条款；
3. Python、React、FastAPI、Fluent UI 等依赖的开源许可证；
4. SOP、安全规则和比赛演示数据的内部授权；
5. 作品名称、界面素材和申报文案的使用范围。

本仓库当前未主动声明开源许可证，不应据此推定可以对外开源或再分发。若计划公开发布，应在法务和知识产权审查后增加明确许可证及第三方 NOTICE。

## 对外表述边界

- 可以表述“支持 DeepSeek API 和离线降级”；
- 可以表述“已在 MASP 数字孪生中验证零资源冲突”；
- 不应表述“DeepSeek 保证调度安全”；
- 不应把仿真吞吐提升当作真实生产收益；
- 不应表述已经获得现场控制准入；
- 不应将安全节点反事实分支描述为中途故障真实续跑；
- 不应表述 AI 已经执行恢复、完成隔离或确认物理根因；
- 任何生产数据出域前必须完成企业合规评估。
